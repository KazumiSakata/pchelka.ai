# Сообщение об уязвимости

Не создавайте публичный issue с токеном, пользовательскими товарами, фотографиями или рабочим эксплойтом. Если владелец репозитория включил GitHub Private vulnerability reporting, используйте Security → Report a vulnerability. Иначе запросите у владельца приватный канал, не публикуя детали. Контакт и сроки ответа владельцем ещё не назначены.

Приложите версию/commit, способ запуска, шаги воспроизведения на учебном товаре и ожидаемый результат. Удалите личные данные.

Реализованные меры, потоки данных и ограничения: [docs/SECURITY.md](docs/SECURITY.md). Поставляется демонстрационный прототип, а не подтверждённое промышленное банковское решение.

# Пчёлка, обновление 24 октября 2026

## Добавлено

- Оригинальная рисованная графика, зелёный и медовый цвета, мягкие переходы, пчёлки по краям экрана, настройка уменьшения движения и поддержка системного reduced motion.
- Подсказки на каждом этапе и у сложных полей. Работают при наведении, фокусе клавиатуры и нажатии.
- 15 новых карточек в день по московскому времени. Расходуется при первом успешном переходе к тексту. Повторное редактирование и скачивание бесплатны. Вариант веса считается новой карточкой.
- Локальный автосохраняемый черновик с фотографиями. При следующем входе можно продолжить или начать заново.
- Написание описания по заполненным полям, продолжение пользовательского текста, сокращение, исправление лишних пробелов. Изменение сначала показывается в редактируемом предложении; есть отмена. Это шаблонная обработка, не генеративная LLM.
- Рекомендации по числу и разрешению фото, вопросы покупателя по незаполненным данным.
- Необязательная диктовка с предварительным предупреждением об обработке аудио браузером. Сначала распознаётся текст, затем показываются редактируемые поля, затем требуется подтверждение. Поля определяются по произнесённым названиям.
- Ручной переход к данным, если модель не загрузилась.
- Поиск, фильтр и выбор товаров в каталоге. Подготовка материалов для одного, нескольких или всех товаров.
- Варианты массы/объёма со сбросом подтверждения. Срок годности, текст и цену нужно проверить заново.
- Резервная копия с фотографиями. Восстановление добавляет товары без перезаписи существующих, сбрасывает подтверждение и не принимает скрипты или SVG-фотографии.
- Самостоятельная HTML-витрина с названием, контактной HTTPS-ссылкой и несколькими товарами. Копирование блока на сайт, скачивание файла.
- Локальное создание QR-кода для введённого HTTPS-адреса уже размещённой витрины. Никакой внешний QR-сервис не получает адрес.
- Учёт ручного размещения: ссылка, статус, зафиксированная цена. При изменении цены показывается напоминание об обновлении объявлений.
- Отметка «Продан» и список связанных объявлений, которые нужно снять вручную. Удаление локальной карточки не удаляет объявления.
- Изменённый пользователем текст объявления включается в комплект ZIP. Переход между площадками заново готовит исходные тексты, изменения в окне не становятся изменениями карточки.
- Запуск в Windows двойным щелчком по start.bat. Python 3 необходим. Платные API и ключи не требуются.

## Границы версии

MobileCLIP-S0 анализирует внешний вид, а не состав и точную марку. Название или штрихкод запрашивается в Open Food Facts; найденный продукт должен подтвердить пользователь. База содержит преимущественно пищевые товары и может быть недоступна.

Нет автоматической публикации, синхронизации, статусов модерации от Авито/Юлы/VK. Все отметки о размещении и снятии вводит продавец. Сервис не подключает аккаунты площадок и не хранит их токены.

Лимит 15 в день хранится в браузере и не является защищённой квотой учётной записи. Для защиты лимита нужен серверный пользовательский учёт. Товары и черновик не синхронизируются между устройствами. Браузер может удалить локальные данные, особенно в приватном режиме.

Витрина экспортируется файлом. Для публичной ссылки её нужно разместить на своём сайте. Корзина, оплата и сервер заказов не добавляются. Голосовой ввод зависит от браузера и сервиса распознавания, полного офлайн-распознавания речи в комплекте нет.

Проверка готовности и словарь спорных обещаний не являются официальной модерацией площадок, юридической экспертизой или проверкой сертификатов.

# Обновление 25 октября 2026

- Главная welcome.html с кнопкой начала, интерактивным примером четырёх этапов, объяснением функций и FAQ. Корневой адрес открывает главную, мастерская остаётся по studio.html. Пример доступен по studio.html?demo=1.
- Сложная анимационная композиция из фотографии, карточки, источника, траектории пчёлок и вращающегося цветка. Анимации разделов при прокрутке, смена демонстрационных сцен, переходы между документами при поддержке браузера и переходы шагов мастерской. Системное и ручное уменьшение движения.
- Увеличены заголовки, ввод, пояснения и кнопки. На телефонах основные действия закрепляются внизу экрана. Поля ввода минимум 16 px для предотвращения автозума на iOS.
- Голосовой ввод заменён на локальный Vosk (vosk-model-small-ru-0.22) вместо SpeechRecognition браузера. Модель и runtime включены в ZIP. Запись микрофона и импорт аудиофайла до 60 секунд, явная остановка, редактирование транскрипта и полей до применения. Простые произнесённые величины переводятся в цифры: «пятьсот граммов» → «500 г». Микрофон требует HTTPS или localhost и разрешения; качество распознавания зависит от записи. Для шумной речи и собственных имён возможны ошибки.
- Реальная локальная генерация описания Qwen2.5-0.5B-Instruct через WebLLM. Доступна при вводе данных, в редакторе и окне подготовки публикации. Написание с нуля, улучшение, продолжение, выбор тона и произвольное пожелание до 600 символов. Результат остаётся редактируемым предложением.
- Для Qwen нужен WebGPU, HTTPS или localhost и около 1 ГБ свободной GPU-памяти. Весовые файлы около 300 МБ скачиваются с Hugging Face по явному действию пользователя и кешируются браузером, в ZIP они не включены. Обработка текста локальная, платного API нет. В среде без WebGPU кнопка генерации выключена с объяснением; обычный редактор и шаблонные функции остаются доступны. Компактная модель не гарантирует качество большой серверной LLM.
- Системный промпт отделяет факты от пожеланий к стилю. Новые числа и известные неподтверждённые обещания блокируют применение. Словарь не доказывает отсутствие всех галлюцинаций, поэтому перед применением обязательно ручное подтверждение. Пустые характеристики не заполняются выдуманными значениями.
- Сохранённые данные продавца: бренд, производитель и контактная HTTPS-ссылка. По включённой пользователем настройке подставляются только в пустые поля новых товаров. Состав, срок и хранение не наследуются.
- Индикатор заполнения обязательных характеристик со ссылками на недостающие поля.
- Подготовка главного фото: поворот, свет, контраст и квадратное кадрирование, предпросмотр и сброс до применения. Не генерирует детали товара. Изменение сбрасывает финальное подтверждение.
- Ценники A4 для выбранных подтверждённых товаров с ценой: автономный HTML без скриптов для печати через браузер.

Проверки: 32 автоматических проверки, синтаксис JS/Python, браузерный путь с главной в мастерскую. Локальная речь проверена на синтетическом русском WAV; распознанную массу удалось перевести в поле 500 г. Физический микрофон пользователя не проверялся. Полная WebGPU-генерация в среде проверки недоступна из-за отсутствия GPU-адаптера; проверены контракт промпта, валидатор, модельные URL и состояние несовместимого устройства. Это ограничение проверки, а не утверждение о работоспособности на любом компьютере.

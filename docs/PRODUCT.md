# Продуктовое решение

Цель: обычный продавец получает готовую карточку для сайта без настройки API и без изучения интерфейса. Основная навигация — четыре последовательных шага. Технические сведения спрятаны в отдельную инструкцию.

1. Фото. Главное фото товара + крупный штрихкод. До 4 файлов JPG/PNG/WebP, 10 МБ, 20 MP каждый.
2. Данные. ИИ предлагает тип и категорию; открытая база возвращает кандидатов. Пользователь подтверждает совпадение упаковки и заполняет неизвестное.
3. Текст и вид. Редактируемый заголовок/описание, цена, ссылка, главное фото, три варианта цвета.
4. Результат. Готовность, короткая предпроверка, явное согласие, HTML для сайта. Дополнительно — сохранение и материалы для площадок.

## Проверки

Готовность: 40 за долю заполненных обязательных полей, 20 за название и описание, 20 за фото, 20 за подтверждение фактов и разрешение противоречий. Это полнота, не вероятность достоверности и не разрешение площадки на продажу.

Для мёда и молочной продукции нужны название, масса/объём, производитель, состав, срок и хранение. Для остальных категорий — название, масса/объём, производитель. Это учебные профили; полноценные схемы расширяются под целевую площадку и вид продукта.

Рискованные медицинские, абсолютные и сертификационные обещания по словарю блокируют выгрузку. Низкое разрешение фото даёт предупреждение. Любая правка данных снимает подтверждение. Предпроверка не анализирует подлинность документов, право на бренд или все правила размещения.

## Реальные полезные функции

- Первое посещение начинается с короткой инструкции.
- Несколько предложений ИИ, а не одно категоричное «это мёд».
- Поиск точного штрихкода с проверкой контрольной цифры.
- Поиск по названию и бренду с ручным выбором совпадения.
- Рядом с импортированным полем — конкретный источник и время получения.
- Бренд и производитель разделены, неизвестный состав остаётся пустым.
- Самостоятельный HTML с фотографией без зависимости от Пчёлки.
- Сохранение товаров на устройстве, открытие, удаление, выбор нескольких/всех.
- HTML-каталог из выбранных товаров.
- Подготовка отдельных объявлений Авито/Юлы и общего/отдельного поста ВК.
- ZIP с исходными материалами по папкам: не нужно вручную искать фото каждого товара.

## Что не выдаём за работающую функцию

Нет авторизованной автопубликации, подключения корзины/оплаты, произвольного поиска по всему интернету, генеративной проверки состава или юридической модерации. Интернет-поиск ограничен Open Food Facts; для непродовольственных товаров покрытие может отсутствовать.

## Следующие функции по приоритету

1. Подключить каталоги производителей по GTIN с явным происхождением данных. Проверять актуальность по рынку и партии.
2. Предложить следующий конкретный вопрос вместо длинной пустой формы. Не заполнять неизвестное автоматически.
3. Подключить официальные аккаунты площадок через разрешённые OAuth/API. Нужны регистрация приложения, права, серверный vault и отдельное подтверждение публикации.
4. Добавить загрузку фото в медиатеку WordPress по официальному API, чтобы избежать ограничений data URI. Только после подключения конкретного сайта.
5. Встроить проверенные профили категорий: дополнительные маркировки, документы и правила площадок с версией и владельцем.

## Проверка пользы

На 30–50 реальных товарах сравнить ручное создание и Пчёлку. Измерять медиану/p90 времени, долю пустых полей после поиска, ошибки сопоставления упаковок, исправления ИИ, время до вставки HTML и возвраты модерации. Отдельно учитывать полный штрихкод, отсутствие товара в базе, частные фермерские марки и неподдерживаемые категории. Полученные результаты не подменять целями проекта.

# Безопасность «Пчёлки»

## Реализовано

- Фото декодируются, уменьшаются до 2200 px по длинной стороне и пересохраняются JPEG без EXIF. Формат проверяется по сигнатуре. Лимит — 4 файла по 10 МБ, 20 MP каждый.
- Модель MobileCLIP и ONNX Runtime размещены на том же сайте. Изображения обрабатываются в Web Worker на устройстве; сервер не получает их. OCR и внешние облачные LLM не используются.
- Штрихкод или текст поиска передаются серверу только для запроса к Open Food Facts. Произвольные URL, тела с фотографиями и пароли API не принимает.
- Сервер обращается только к фиксированным HTTPS-хостам world.openfoodfacts.org и search.openfoodfacts.org. Редиректы не следуются в размещённом Worker. Размер ответа ограничен 1 MB, таймаут 15 секунд, результаты — максимум 5.
- Входная строка ограничена 2–120 символами, для цифрового GTIN проверяется длина и контрольная цифра. Синтаксические управляющие символы поискового запроса удаляются.
- Установлен лимит 10 поисков в минуту по IP в текущем изоляте/процессе. Это не распределённый rate limiter.
- Значения из источника выводятся как экранированный текст. URL источника строится из цифрового кода, внешние миниатюры разрешены только с images.openfoodfacts.org.
- CSP ограничивает скрипты, соединения и Workers. WASM-разрешение необходимо для локального инференса. Нет unsafe-eval для обычного JS. Для inline-стилей требуется style-src unsafe-inline.
- Готовая карточка не содержит JS. Изображение включается только как разрешённый data:image JPEG/PNG/WebP base64. Кнопки принимают только HTTPS без логина/пароля; пользовательский текст экранируется.
- Перед экспортом обязательны заполнение, проверка текста и явное подтверждение. Ручная правка сбрасывает подтверждение.
- В сервисе не запрашиваются пароли, cookies, токены Авито, Юлы или ВК. Внешние переходы не публикуют товары. Публикация остаётся в аккаунте площадки.
- Сохранение товаров — IndexedDB браузера по явной команде. Черновик с фото автоматически сохраняется в отдельной локальной базе. На сервере нет фотографий или базы пользовательских карточек. Удаление в «Мои товары» удаляет локальную запись; скачанные файлы остаются у пользователя.

## Ограничения

Браузер всё равно декодирует недоверенный файл: проверка размера не является антивирусом. Используйте актуальный браузер. Изолированный Worker не равен банковскому sandbox. Данные IndexedDB не шифруются приложением; человек с доступом к профилю браузера может получить их. Очистка данных сайта удаляет товары. В скачанном HTML фото и свойства открыты любому получателю файла.

Источник Open Food Facts заполняется сообществом и не удостоверяет состав, подлинность или сертификаты. Совпадение штрихкода и визуальная классификация не снимают необходимость проверить конкретную упаковку. Текущий словарь предпроверки неполон.

Размещённый сайт сохраняет настроенный режим доступа платформы. Локальный server.py привязан к 127.0.0.1, не является защищённым публичным production-сервером. В Docker порт хоста также ограничен localhost; root, лишние capabilities и запись в файловую систему отключены.

## Для промышленного банковского контура

SSO и роли нужны при переходе к серверной базе/командной работе. Для такой версии нужны изоляция организаций, владение объектами, шифрование, retention, неизменяемый аудит, scanner/quarantine для серверных загрузок, KMS/vault и SCA/SAST/pen-test. Для прямой публикации на площадках — зарегистрированные приложения, разрешённые API, защищённое хранение токенов и отдельное согласие на отправку.

Модель и runtime зафиксированы в поставке, лицензии приложены. Это воспроизводимость, не утверждение отсутствия CVE. Перед промышленным запуском проверять зависимости, модельные артефакты, лимиты и права на данные. Пилот не является сертифицированным банковским решением.

Источники: OWASP File Upload Cheat Sheet (https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html), MobileCLIP (https://github.com/apple/ml-mobileclip), Open Food Facts API (https://openfoodfacts.github.io/openfoodfacts-server/api/). Проверены 23.10.2026.


## Новые локальные функции

Лимит 15 в сутки хранится в localStorage, изменение часов или очистка данных обходят его. Это UX-ограничение без аккаунтов, не средство защиты от злоупотреблений. navigator.locks координирует расход лимита между вкладками при наличии поддержки.

Резервная копия содержит открытые пользовательские данные и фото. Импорт ограничен 100 МБ, 100 товарами и 4 фото на товар. Разрешены только base64 JPEG/PNG/WebP. Права, источники и подтверждение не импортируются. Поля ограничиваются по длине; ссылки проходят HTTPS-проверку; тексты экранируются. Импорт выполняется одной транзакцией. Он не декодирует фото до их отображения, поэтому проверка не заменяет безопасный браузер.

Ссылки размещения ограничены доменами соответствующей площадки и HTTPS, встроенные логин/пароль отклоняются. Эти ссылки и статусы вводит человек, подтверждения от площадок нет. QR-код создаётся локально, без внешнего сервиса.

Голосовой ввод вызывается только после отдельного нажатия. В версии от 25 октября используется локальный Vosk в WebWorker; аудио не передаётся поставщику браузерного распознавания. Нужны разрешение микрофона, HTTPS/localhost. При закрытии записи останавливаются медиадорожки и освобождается аудиоконтекст. Временная FS модели находится в памяти. CSP не ослаблена до unsafe-eval: динамические binding-фабрики заменены статическими замыканиями.


## Локальный генератор текста

WebLLM и WASM-библиотека включены в поставку. Веса Qwen скачиваются с фиксированной ревизии публичного репозитория Hugging Face по действию пользователя. CSP разрешает загрузку с Hugging Face и его CDN под hf.co, но текст товара и промпт туда не отправляются. Нейросеть запускается в браузере через WebGPU. Системный промпт не является границей безопасности: применение предложения требует проверки, известные новые численные значения и неподтверждённые обещания блокируются. Генерируемый текст попадает только в текстовые поля, не исполняется как HTML или JS. Полная защита от галлюцинаций и prompt injection не заявляется. Пользовательская правка и обработка фото сбрасывают финальное подтверждение.

# Проверки поставки — 25.10.2026

## Выполнено

- Python 3.12: 8 HTTP-тестов реального Handler с локальным сервером на случайном порту. Проверены главная, заголовки, OpenAPI, WASM MIME, валидация, лимит, ошибки источника, метаданные кандидатов и недоступность исходников вне public/. Интернет-источник в тестах подменён; это не проверка живой базы.
- Node.js: 16 проверок engine, 10 workbench и 6 plus. Итого с HTTP — **40 пройденных проверок**. Установка npm-зависимостей не требовалась.
- YAML: compose.yaml и файлы GitHub Actions/Dependabot прочитаны парсером. Это не эквивалент docker compose config.
- Ссылки новых Markdown-документов проверены на существование локальных файлов.
- Все файлы исходного полного ZIP сохранены. Сверка частей моделей с исходным архивом — байт-в-байт. Редактировались документы, метаданные Git/Docker и схема HTTP; исходный код приложения не менялся.
- RELEASE_MANIFEST.json содержит SHA-256 файлов. Для текста нормализуется CRLF → LF, бинарные модели, PDF/PPTX и картинки проверяются по точным байтам. Команда проверки: python scripts/verify-release.py.
- Итоговый ZIP проверен чтением CRC каждой записи и сверкой распакованных файлов с манифестом.
- Презентация: 39 слайдов; структурная проверка PPTX и визуальный просмотр, PDF экспортирован и проверен отдельно.

## Не выполнено / ограничения

- Docker Engine в среде подготовки отсутствует: сборка и запуск контейнера локально не выполнены. Workflow Pchelka checks выполняет docker compose config и build/run после выгрузки на GitHub; результат CI заранее не заявляется.
- Полная генерация Qwen на GPU не проверена: в браузере подготовки отсутствует WebGPU-адаптер. Проверены логика промпта, валидатор и сообщение о несовместимости. На целевом устройстве требуется проверка модели.
- Для Vosk в предыдущей версии проверен синтетический русский WAV. Микрофоны и реальная речь конкретных пользователей требуют проверки.
- Node/Sites установка и сборка повторно не запускались. Переносимый путь поставки — Python/Docker; исходный платформенный контур сохранён без потерь.
- Промышленный деплой, SSO, банковский аудит, живые публикации и нагрузочный тест не выполнялись. Время три минуты и коммерческий эффект не измерены.

## Повторить

```sh
python -m unittest discover -s tests -p "test_*.py" -v
node tests/test_engine.mjs
node tests/test_workbench.mjs
node tests/test_plus.mjs
python scripts/verify-release.py
```

При наличии Docker дополнительно выполнить команды из DEPLOYMENT.md. Технические проверки не подтверждают корректность фактов любого товара и не заменяют ручное согласие.

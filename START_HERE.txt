ПЧЁЛКА. ЗАПУСК ЗА ДВА ДЕЙСТВИЯ

1. Распакуйте архив целиком, откройте папку pchelka.
2. Дважды нажмите start.bat. Оставьте открывшееся окно.

Откройте http://localhost:8000
Нужен установленный Python 3: https://www.python.org/downloads/
Если предлагается установка Python, отметьте Add Python to PATH.
Docker, платные API и ключи не нужны.

macOS / Linux: sh start.sh
Docker (необязательно): docker compose up --build -d

КАК ПОЛЬЗОВАТЬСЯ
Главная → Начать → фото → данные → текст → проверка и готовая карточка.
В первый раз появится инструкция. Для примера нажмите «Попробовать на упаковке мёда».
ИИ MobileCLIP-S0 запускается в браузере. Файлы модели уже включены в архив.
Поиск сведений в Open Food Facts требует интернета. Неизвестные факты не подставляются.

15 новых карточек в день. Редактирование не тратит лимит.
Лимит и каталог хранятся в этом браузере. Скачивайте резервные копии через «Мои товары».

Авито / Юла / VK: сервис готовит тексты и фото. Размещение завершается вами на площадке.
Ссылки на публикации можно сохранить через «Мои товары → Действия».
Автоматическая публикация без API не включена.

Полный список изменений: docs/WHATS_NEW.md
Защита и ограничения: docs/SECURITY.md
Интеграция с сайтом: public/integration.html (или ссылка «Разработчику»).

НОВОЕ: НЕЙРОСЕТЬ ДЛЯ ОПИСАНИЯ
Кнопка «Написать с нейросетью» / «Помочь с описанием» доступна на этапах данных, текста и подготовки публикации.
Нужны Chrome/Edge с WebGPU, аппаратное ускорение и около 1 ГБ памяти видеокарты.
Первый запуск скачивает около 300 МБ публичных весов. API-ключ и оплата не нужны.
Если WebGPU недоступен, обычное редактирование и шаблонный текст продолжают работать.

ГОЛОС
Русская модель Vosk уже в архиве. Разрешите микрофон на localhost либо выберите WAV/MP3 до 60 секунд.
Проверьте транскрипт и поля до применения. Аудио не отправляется на сервер.

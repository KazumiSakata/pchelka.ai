# Пчёлка

Сервис для создания карточек товаров по шагам. Откройте опубликованный сайт, ничего устанавливать и вводить API-ключи не нужно.

## Обновление

Главная страница, крупные элементы, анимации, 15 карточек в день, автосохранение, локальные Qwen2.5 и Vosk, обработка фото, ценники A4, данные продавца, варианты веса, каталог, резервная копия, витрина с QR-кодом и учёт ручных публикаций. Подробнее: [docs/WHATS_NEW.md](docs/WHATS_NEW.md).

### Быстрый запуск Windows

Распакуйте ZIP целиком. Откройте папку `pchelka` и дважды нажмите **start.bat**. Нужен Python 3; окно сервера оставьте открытым. Откройте http://localhost:8000. Docker и ключи не нужны.

## Что делает пользователь

1. Загружает фото товара и крупное фото штрихкода.
2. Запускает ИИ. MobileCLIP предлагает тип и категорию по изображению. Штрихкод используется для поиска конкретной упаковки в Open Food Facts.
3. Сравнивает найденную запись с упаковкой, подтверждает совпадение. Название, бренд, масса и состав переносятся только после этого действия. Недостающие сведения заполняет с упаковки.
4. Проверяет поля, создаёт текст, при желании добавляет цену и ссылку.
5. Подтверждает карточку и копирует готовый HTML для сайта или скачивает HTML/ZIP. Фото и оформление включены.

При первом входе открывается инструкция из трёх экранов. Её можно повторить кнопкой «Как пользоваться».

## Мои товары и площадки

Подтверждённую карточку можно сохранить в браузере. В «Мои товары» доступны выбор одного, нескольких или всех товаров, HTML-каталог, материалы для Авито/Юлы и отдельный или общий пост ВК.

Пчёлка бесплатно готовит тексты и JPG-фото. ZIP не является файлом автозагрузки. Объявления и посты публикуются вручную в аккаунте площадки; аккаунты не подключены к сервису. Цены размещения и лимиты определяются площадками. Не вводите пароли от Авито, Юлы или ВК в Пчёлку.

## Что именно делает ИИ

Визуальная модель MobileCLIP-S0 работает на устройстве через ONNX Runtime Web. Она сравнивает фото с 34 описаниями типов товаров, показывает несколько вариантов и численный индекс сходства. Это настоящий анализ изображения. OCR в этой версии не используется.

Тип товара не равен бренду, составу или сертификату. По фотографии банки нельзя достоверно определить её содержимое. Данные конкретного продукта запрашиваются из открытой базы. Бренд из базы не подставляется как производитель. Срок и условия хранения не выводятся из типа товара. Для товара, которого нет в базе, нужные поля остаются пустыми.

Первый запуск скачивает около 45 МБ весов модели и около 11 МБ среды выполнения с самого сайта. На слабых устройствах анализ может занять больше времени. Время «три минуты» — цель сценария, не SLA. Помощник Qwen2.5 создаёт свободный текст локально через WebGPU по заполненным данным и пожеланию. Поиск свойств и генерация текста разделены. Первое включение Qwen скачивает около 300 МБ публичных весов, нужна совместимая видеокарта и около 1 ГБ GPU-памяти. Веса Qwen в ZIP не включены; runtime и конфигурация включены. Без WebGPU работают обычный редактор и шаблонные функции. Генеративная модель может ошибиться: проверка новых чисел/спорных фраз и ручное подтверждение обязательны.

Голос распознаётся моделью Vosk на устройстве. Её веса около 45 МБ включены в поставку. Доступны микрофон (HTTPS/localhost и разрешение) и аудиофайл до 60 секунд. Сначала исправьте распознанный текст и поля, затем подтвердите перенос.

## Файлы для интеграции

- HTML-файл: открывается двойным щелчком, содержит выбранную фотографию и inline-стили, не содержит JS.
- HTML-блок: вставляется в блок HTML/Код редактора сайта.
- Каталог: несколько выбранных карточек в адаптивной сетке.
- ZIP для площадки: папка на товар, название, описание, цена, JPEG-фото и инструкция.
- `public/integration.html`: конкретные способы вставки и API.
- `public/api-contract.json`: контракт HTTP-поиска.

CMS могут удалять встроенные изображения или стили. В этом случае загрузите фото в медиатеку и замените src в готовом HTML либо передайте файл администратору сайта. Карточка не добавляет корзину, оплату, остатки или учёт заказов.

## Локальный запуск, если нужен

Основной способ использования — опубликованный сайт. Для локальной копии достаточно Python 3:

```sh
python server.py
```

Затем http://localhost:8000. Зависимости Python, API_TOKEN и .env не нужны. На Windows можно выполнить `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Скрипт сам перейдёт в папку проекта. Распакуйте архив полностью, не запускайте его из окна ZIP.

Docker остаётся необязательным вариантом:

```sh
docker compose up --build -d
```

Фотографии и сохранённые карточки находятся в браузере, а не в Docker. Старый файл .env от ФАКТУРЫ больше не используется. Локальный сервер Python предназначен для демонстрации на своём компьютере, не для публичного промышленного хостинга.

## Для разработчика

Размещённая версия: Vinext + Cloudflare Worker, публичные статические файлы в `public/`, серверный GET `/api/products`. JS API: `PchelkaVision.classify`, `Bee.check`, `Bee.card`, `Bee.html`, `Bee.zip`, `Bee.announcement`. Интерфейс реализует проверки и ручное подтверждение вокруг низкоуровневых функций.

Полный checkout содержит `package.json`, lockfile и app/worker/scripts для хостинга. Установка и dev-запуск:

```sh
npm install
npm run dev
```

Для воспроизводимости на pnpm используйте приложенный lockfile и `pnpm install --frozen-lockfile`. Изменять пользовательский путь для локального запуска не требуется: Python-версия обслуживает ту же страницу и тот же поиск.

## Данные и ограничения

Текущая схема обязательных полей — профиль пилота, не полная юридическая схема маркировки. Источник Open Food Facts заполняется сообществом, может быть неполным и ошибочным. Всегда показываются ссылка и время получения. Зафиксированный источник включён в готовую карточку с атрибуцией ODbL.

Сохранённые товары доступны только в том же браузере и на том же домене. Это не резервная копия и не синхронизация между устройствами. Черновик автоматически сохраняется в этом браузере примерно раз в 5 секунд и предлагается к восстановлению при следующем входе. Последние изменения до очередного сохранения могут быть потеряны. Приватный режим и очистка данных браузера могут удалить товары.

Меры безопасности и план промышленного продолжения: `docs/SECURITY.md`. Права и уведомления сторонних компонентов: `docs/THIRD_PARTY.md` и `public/ai/`.

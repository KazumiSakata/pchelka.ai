Добавление карточек на сайт

Для обычного пользователя: создайте карточку → подтвердите → «Скопировать карточку» → вставьте в HTML-блок сайта. Фото и inline-стили находятся внутри блока. Корзина и оплата не добавляются.

Один или несколько товаров

Сохраните подтверждённые карточки в «Мои товары». Выберите одну, несколько или все. Кнопка «На сайт» создаёт готовый адаптивный каталог. Кнопки площадок собирают тексты и фотографии для ручного размещения.

JavaScript API

Подключите engine.js, vision.js и папку ai/ на своём сервере. При переносе сохраните уведомления и лицензии модели и библиотек. Встраивание анализатора на отдельном сайте требует адаптации пути к файлам модели.

<script src="/pchelka/engine.js"></script>
<script src="/pchelka/vision.js"></script>
// Анализ фотографии, данные фото остаются на устройстве
const ranked = await PchelkaVision.classify(cleanPhotoDataUrl);
// ranked: [{key, name, category, similarity}, ...]
// similarity — косинусное сходство, не вероятность истинности.

// Проверка после сверки всех полей человеком
const issues = Bee.check(product);
if (userConfirmed && !issues.some(x => x.type === 'block')) {
  const block = Bee.card(product); // HTML с фото и стилями
  const file = Bee.html(product);  // Полная HTML-страница
}

Методы Bee.card и Bee.html — низкоуровневые рендереры. Они экранируют текст, но не заменяют проверку и ручное согласие. Путь подтверждения реализован в app.js и workbench.js. Локальные функции дополнены модулем workbench-core.js.

HTTP API интернет-поиска

GET /api/products?q=3017620422003
GET /api/products?q=название%20бренд

Поиск выполняется на том же сервере, который обслуживает приложение. Ключ пользователя не нужен. Принимается только штрихкод или строка длиной 2–120 символов. Фото, пароли, произвольные URL и HTML не принимаются.

ОтветЗначение
200source, license, retrieved_at, matched_by, products. Пустой products означает отсутствие совпадений.
400Неверная строка или контрольная цифра штрихкода.
429Больше 10 поисков в минуту в текущем процессе/изоляте.
503Источник не ответил. Не заменять отсутствие результата догадкой.

Поиск по имени возвращает кандидатов, а не точное совпадение. Даже совпадение по штрихкоду сверяется с конкретной упаковкой. Источник: Open Food Facts, ODbL. Данные заполняются сообществом, могут быть неполными. Бренд не равен производителю. Состав не устанавливается визуальной моделью.

Авито, Юла и ВКонтакте

В текущей версии создаются материалы для размещения: тексты по товарам, JPG-фото, общий пост ВК и инструкция. Авторизованная автопубликация к аккаунтам не подключена. Кнопка открытия площадки ничего не публикует. Тарифы и лимиты определяет сама площадка.

Помощник текста и локальная квота

Bee.description(values, "create")
Bee.description(values, "continue", userText)
Bee.buyer(product)
Bee.claim(dayState, draftId)

Это локальные функции без ключей. Описание собирается из полей. Квота ограничена браузером: 15 новых черновиков в сутки по Москве. Для серверной защиты нужен отдельный пользовательский учёт. Ручные статусы объявлений не являются подтверждением от площадки.

Локальный запуск

python server.py

Откройте localhost:8000. Python-сервер из комплекта использует только стандартную библиотеку и проксирует те же открытые источники. Никакие API_TOKEN и .env не нужны. Размещённая версия работает сразу по ссылке.

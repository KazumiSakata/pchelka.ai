# Минимальный пример встраивания

1. Запустить основной сервис `python server.py` из корня.
2. Открыть http://localhost:8000/integration.html — инструкция, доступная и в самом приложении.
3. Для собственного сайта скопировать `public/engine.js`, `public/sample-product.jpg` и этот `card-example.html` в одну папку и раздавать её обычным статическим сервером.
4. Открыть пример, проверить учебные поля, нажать подтверждение, затем кнопку создания блока.

Пример ничего не публикует и не обращается к платным API. Учебная карточка не подходит для реальной продажи. В CMS используйте готовый блок из основного приложения или включите движок в свою страницу и реализуйте собственное подтверждение. Не передавайте в рендерер произвольный чужой HTML.

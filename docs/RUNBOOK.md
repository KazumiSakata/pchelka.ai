# Эксплуатация и восстановление

## Обычная работа

Запустите start.bat/Python или Docker из DEPLOYMENT.md. Не закрывайте окно Python во время работы. Сервер не сохраняет фото или карточки; браузер сохраняет каталог и черновик. В браузере на другом домене, порту, устройстве или профиле это другой каталог.

## Резервная копия

1. «Мои товары» → «Скачать резервную копию всех товаров».
2. Сохранить файл вне репозитория, например в личной защищённой папке.
3. На новом устройстве открыть сервис → «Мои товары» → «Восстановить из копии».
4. Проверить товары и заново подтвердить сведения перед экспортом. Права и подтверждение не переносятся автоматически.

Backup содержит фото и сведения в открытом виде. Не добавляйте его в GitHub. Удаление локальной записи не удаляет уже скачанные HTML/ZIP и стороннее объявление. Изменение статуса «Продано» в Пчёлке не снимает публикацию на площадке.

## Диагностика

| Симптом | Что сделать |
|---|---|
| Python не найден | Установить Python с python.org; Windows — включить PATH либо использовать py -3 |
| Порт 8000 занят | Остановить предыдущую копию. Либо выбрать --port 8001, учитывая отдельное хранилище браузера |
| Нет WebGPU | Актуальный Chrome/Edge, аппаратное ускорение, совместимый GPU. Если недоступно — ручной редактор/шаблон |
| Модель не скачивается | Проверить интернет и доступ к Hugging Face; повторить по действию пользователя. Не удалять части модели из public |
| Голос не запускается | HTTPS/localhost, разрешение микрофона; попробовать аудиофайл до 60 секунд/15 МБ. Проверить устройство |
| Поиск 503 | Источник недоступен: заполнить по упаковке, не подставлять догадки |
| Поиск 429 | Подождать минуту. Это лимит 10 поисков на IP в процессе/изоляте |
| CMS убрала фото | Загрузить фото в медиатеку CMS и заменить src; HTML-файл проверить отдельно |
| Пустой каталог после обновления | Проверить адрес, порт и профиль браузера; восстановить свою резервную копию |

## Обновление

До замены файлов экспортируйте каталог. Остановите сервер, распакуйте новую версию, проверьте манифест, запустите заново на прежнем адресе. В Docker пересоберите образ. Сначала проверьте новую версию на учебном товаре. Для отката верните предыдущую поставку и нужную копию данных; не гарантируется переносимость будущих схем backup назад.

## Перед выдачей публичного адреса

Определить владельца, доступ, HTTPS, мониторинг, лимиты запросов и политику хранения. Проверить модели на целевых устройствах, источники, лицензии и безопасность зависимостей. Контейнер и CI не заменяют эти решения.
